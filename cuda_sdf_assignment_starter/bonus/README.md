# 选做加分：固定拓扑动态三角网格 SDF 更新（最高 10 分）

**本任务不是静态 SDF 基础 100 分的完成条件。** Starter 的主接口 `student_sdf_cuda(...)` 及 `run_demo.py` 均以静态单帧计算为主。`deform_000.obj`、`deform_001.obj`、`deform_002.obj` 现仅是三份独立可运行的公开示例；反复执行静态计算不等价于具备 GPU 增量更新能力。

## 任务

设三角形拓扑与索引完全固定，依次将每帧新的顶点坐标传入 GPU，并生成正确的 SDF。允许在多帧之间复用静态拓扑数据、GPU 分配和合规缓存，但新帧的 SDF 必须由当前帧几何生成。提交独立可复现的 bonus 构建/运行说明与代码。

建议的接口逻辑（**不是当前教师已实现的 ABI**）：

1. `initialize(vertices0, triangle_indices, grid)`：初始化持久资源。
2. `update(vertices_frame, stream)`：上传/接收当前顶点位置，重建必要辅助结构。
3. `compute(output, stream)`：计算该帧 SDF。
4. `release()`：销毁资源。

接口将由教师在真正提供动态驱动后冻结；当前请勿为完成静态必做任务修改 `student_sdf.cuh` / 教师驱动。

## 加分规则（最多 10 分）

| 项目 | 分值 | 证据 |
|---|---:|---|
| 多个变形帧均输出正确 SDF | 3 | 每帧与独立参考比对 |
| 复用拓扑与显存等持久资源 | 2 | 代码与峰值显存记录 |
| 具备真实动态更新优化 | 3 | 对比每帧全量重建的消融与性能收益 |
| 端到端计时与性能分析 | 2 | H2D + 更新 + 计算 + 规定传输的逐帧数据 |

总评分 `min(100, 基础成绩 + 合格的动态加分)`；可不参加。正式成绩须由教师确认，**当前包没有自动加分判题器或可信动态流式计时器**。
