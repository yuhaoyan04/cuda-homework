## 算法

一个 CUDA 线程负责一个采样点，按 `i + nx*(j + ny*k)` 写出结果。线程遍历全部三角形，使用 Ericson 最近点区域算法求点到三角形面的距离；沿 +X 射线进行奇偶交点判定，内部取负。射线 Y/Z 坐标加确定性微小偏移以减少共享边歧义。Kernel 使用驱动传入的 stream，填充所有输出，额外显存为 O(1)。

复杂度为 O(nx·ny·nz·T)，T 为三角形数。实现包含两项可独立关闭的优化：AABB 距离下界跳过不可能成为最近面的三角形距离计算；投影到 YZ 平面的包围盒跳过不可能相交的射线三角形测试。后者仅剪掉投影包围盒外的点，不会剪掉有效交点。输出按网格线性索引连续写入。

该实现是穷举扫描，不适合极大网格或高面数压力场景。封闭且一致的输入网格是符号判定前提；极端坐标范围和退化三角形尚未专项评估。

## 正确性验证

所有下列 GPU/CPU 对比均使用公开 demo 的暂定 `0.1*dx` 门槛；这不是课程最终隐藏评分标准。

| 用例 | 网格 / 三角形 | MAE | 最大误差 | 符号错误率 | 结果 |
|---|---:|---:|---:|---:|---|
| cube_32 | 32³ / 12 | 3.83e-8 | 1.79e-7 | 0 | PASS |
| sphere_32 | 32³ / 80 | 3.21e-8 | 1.79e-7 | 0 | PASS |
| torus_64 | 64³ / 1024 | 7.64e-7 | 6.97e-4 | 0 | PASS |
| two_cubes_64 | 64³ / 24 | 6.89e-8 | 2.40e-7 | 0 | PASS |

torus GPU 输出另经独立精确点-三角形无符号距离抽样（256 点）核验：MAE 7.53e-8，最大误差 2.17e-7，0 个超限样本。立方体 smoke 16³ 解析验证通过。`python3 tools/check_package.py` 和 `python3 -m unittest discover -s tests -v` 通过（13 项）。

## 优化消融

H800、CUDA Events 只计 `student_sdf_cuda` 中的 GPU 工作，不包含 H2D/D2H。测试为 torus 64³、1024 三角形、预热 2 次、重复 5 次。每个版本对 CPU 的暂定比较均 PASS，平均和符号结果相同。

| 版本 | 开启优化 | 中位数 ms | 相对基础版 |
|---|---|---:|---:|
| baseline | 无 | 1.5861 | 1.00× |
| opt-AABB | 距离 AABB 下界剪枝 | 1.5989 | 0.99× |
| opt-ray | YZ 投影包围盒射线剪枝 | 1.3992 | 1.13× |
| opt-AABB+ray | 两项剪枝 | 1.2310 | 1.29× |

本次输入上距离 AABB 剪枝单独略慢，显示它的比较/分支开销超过节省的距离计算；和射线剪枝结合时总耗时最低。投影包围盒筛除大部分无关三角形射线运算，单项有约 11.8% 收益。没有 Nsight profiler 计数器，本分析只基于 CUDA Events 数据。原始时间序列及对应 CPU 对比 JSON 在 `docs/ablation/`。
