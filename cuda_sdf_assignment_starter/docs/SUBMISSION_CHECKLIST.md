# 提交清单（学生）

**静态 SDF 是必做；动态 SDF 仅选做。** 具体截止时间、提交平台和最终文件命名请遵守课程另行通知。

## 基础 100 分（必交）

- [ ] `student/student_sdf.cu`：完整 CUDA 静态 SDF 实现；附必要的授权辅助文件与构建说明。
- [ ] 算法与实现说明：输入输出、符号判定、线程组织、GPU 内存与同步、复杂度。
- [ ] 编译运行记录：操作系统、GPU/驱动、CUDA Toolkit、CMake 参数、Release 配置和具体运行命令。
- [ ] 正确性报告：至少立方体、球面、环面和两个分离立方体，含校验报告及对失败用例的解释。
- [ ] 性能报告：基础版与至少两项优化逐项消融，记录原始 GPU Events 数据和中位数、测试规模与计时边界。
- [ ] 使用 `docs/EXPERIMENT_REPORT_TEMPLATE.md` 提交完整报告；代码和数据足够复现。

## 动态加分（自愿）

- [ ] 固定拓扑多帧更新代码及独立运行说明。
- [ ] 每帧 SDF 正确性、缓存/显存复用与相对重算的性能收益。
- [ ] H2D/更新/计算/必要传输的端到端逐帧原始数据。

**请勿修改**公开验证器、GPU 驱动的判题逻辑、CPU 参考与数据。不要提交 `build/` 等编译缓存或整个 `results/` 的大体积重复文件；按教师指定的格式保留必要原始报告。教师最终将使用可信驱动重编译和验证。
